## Open Reports

I maintain [Open Reports](https://github.com/varaprasadreddy9676/open-reports), an MIT-licensed, self-hosted report designer and rendering engine for application teams. Design reports with JSON templates, embed the designer in your application, and render documents through an API.

- [Try the live demo](https://open-reports-demo.onrender.com/)
- [Source code and setup guide](https://github.com/varaprasadreddy9676/open-reports)
- [Embedding walkthrough](https://youtu.be/0jjQKdJYMYg)

Open Reports is early v0.x. JRXML imports create drafts that need review; compiled `.jasper` files and full JasperReports compatibility are not supported. The hosted demo is shared, so use sample data only.
